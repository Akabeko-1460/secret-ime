# 最小版の設計と保証範囲

決定日：2026-10-31。ユーザーのGo判断により、先行調査の保留を解除してPrivate alphaを作る。
技術的な未実証事項はGo承認によって成功扱いにはしない。

## 必要な構成だけを用いる

拡張はJavaScriptのMV3 Service Workerで、常時ポーリングをしない。
private窓のイベントを受けたときに状態を照合する。
入力欄を読むcontent script、tabs権限、閲覧権限は使わない。

Windows側はOSの.NET Frameworkで動作する小さなC#ホストとする。
RustやTypeScriptを採用するための追加ツールチェーン・依存取得を避けた。
外部ライブラリや重いUIフレームワークのアプリ画面は作らない。
ビルド時にUI AutomationのOS付属アセンブリを参照する。

Chromeが起動するstdioホストは、同じユーザーの単一ブローカーへ接続する。
ブローカーは接続ごとにleaseを持ち、他のブラウザが残っている間は明示復元を拒否する。
最後の接続が終わると、250msの終了猶予の後に停止する。
同じユーザー・同じ対話セッション・同じ実行ファイルの通信相手だけを許可する。

UI Automationは別の自前ワーカーで行い、プロバイダーの停止を12秒単位で検出する。
固まった自前ワーカーは終了できるが、GoogleのIMEプロセスやブラウザは終了しない。
Windows起動時の常駐やサービスは登録しない。

## 状態変更は確認してから行う

アダプターは標準配置にあるGoogle署名付きの公式ツールだけを起動する。
署名検証はキャッシュのみを使い、検証のためのネットワーク取得を行わない。
既存の設定画面は、ユーザーの編集を保護するため再利用しない。

新しく開いた画面で、`incognitoModeCheckBox`という識別子、または実機で確認したQt完全修飾IDと、チェックボックス型を確認する。
チェック状態を取得できたときだけ、必要な方向へ1回操作する。
保存後に新しい画面で読み直す。
名前だけの類似項目、座標、ショートカット、未知の内部IPC、設定ファイルの直接編集にはフォールバックしない。

公式UIの起動モード・識別子は[Mozcの公開実装](https://github.com/google/mozc/blob/master/src/gui/config_dialog/config_dialog.ui)を調査した候補であり、製品版の外部API保証ではない。
製品版3.34.6260.0では、Qt完全修飾IDとTogglePatternを用いた設定読取を確認した。
他の版が必要なUIパターンを公開しない場合、このアダプターは利用不可となる。

## 復元は明示操作だけにする

開始時ONなら設定の所有権を取得しない。
OFFからONを確認した変更だけを記録する。
書込み前にはdirtyマーカーを保存し、正常終了時だけclean-ownedへ更新する。
未知状態・途中の手動OFF・異常終了では所有権を推測しない。

明示復元は全leaseが終了した後だけ行う。
正常終了の所有権は次のブローカーへ引き継げるが、停止中の手動変更まで識別した保証はない。
そのため自動OFFは提供せず、最新状態を確認した利用者の操作を必要とする。
dirtyマーカーが残る場合は、Googleの公式設定で手動確認する。

## 状態の表示と実効性を分ける

`mode-enabled`は、設定操作時にUIのONを確認した意味である。
継続監視・入力前の同期・永続学習停止を意味しない。
設定後の手動変更、IME切替、ウィンドウを開く直前の入力競合は未解決である。
`effectiveness`は常に`unverified`とする。

[ChromiumのTSF実装](https://chromium.googlesource.com/chromium/src/+/main/ui/base/ime/win/tsf_input_scope.cc)にはprivate通知があるが、IMEの保存抑制とは別である。
[Mozc #1593](https://github.com/google/mozc/issues/1593)も、製品版Google日本語入力の永続学習漏れをそのまま証明しない。
Microsoft IMEの標準保護には介入せず、実機検証を別Issueで追跡する。

## データと権限

通信は版・操作・要求の有無・固定状態コードだけとする。
フレームは最大2048バイトで、未知キー、重複、型不一致、壊れたUTF-8、途中EOFを拒否する。
ホストの接続元は拡張IDを正確に限定し、pipeは現在ユーザーのACLと実行ファイル照合で保護する。
入力・候補・URL・履歴・辞書を読まず、テレメトリと外部送信も行わない。

拡張は設定と最後の確認結果・復旧の可能性をローカル保存する。
ホストは`build/`に小さな復旧マーカーとその前版を残す。
アプリ停止中の同値手動変更や、同じユーザーが意図的に改ざんする行為を防ぐ仕組みではない。
更新時はすべての連動接続を閉じてからビルド・再登録する。

Google日本語入力本体の改変・再配布や、未公開APIの使用は行わない。
公開規約を確認したことを、製品版のUI自動化に対するベンダー保証・ストア審査完了・法的適合の無条件保証には読み替えない。
ストア配信、署名付きインストーラー、全組合せの実機検証はこの最小版の範囲に含めない。
