# Setup.exeから導入する

Windows 11 x64でGoogle日本語入力を使う方向けの試験版です。
実際の学習停止とChrome・Edge・Brave・Vivaldiの互換性は未検証です。

## 1. Setupを実行する

[リリース一覧](https://github.com/Akabeko-1460/secret-ime/releases)から最新の`SecretIME-…-Setup.exe`を取得し、ダブルクリックします。
ZIPの展開、追加ソフト、PowerShell操作、管理者権限は不要です。
Privateの間はリポジトリへのアクセス権が必要です。

Setupには現在コード署名がありません。Windowsの保護機能で警告・ブロックされる場合があります。
入手元と配布元のSHA256を確認し、判断できなければ実行を見送ってください。
セキュリティ機能や実行ポリシーを一括で無効にする必要はありません。

確認欄を選び、「導入する」を押してください。
現在のWindowsユーザーの`%LOCALAPPDATA%\Programs\SecretIME`へ配置します。
セットアップ中にGoogle日本語入力の画面を開いたり、IME設定を変更したりはしません。

## 2. ブラウザに拡張を読み込む

使うブラウザごとに次の操作をします。

| ブラウザ | アドレス欄に入力する管理画面 |
| --- | --- |
| Chrome | `chrome://extensions` |
| Edge | `edge://extensions` |
| Brave | `brave://extensions` |
| Vivaldi | `vivaldi://extensions` |

1. デベロッパーモードをONにします。
2. 「パッケージ化されていない拡張機能を読み込む」を選びます。名称はブラウザで多少異なります。
3. Setupの「拡張フォルダーをコピー」を押し、フォルダー選択欄へ貼り付けて選択します。
4. SecretIMEの「詳細」を開き、シークレット／InPrivateなどでの実行を許可します。
5. 拡張アイコンを押し、ポップアップで連動をONにします。

読み込み先は`%LOCALAPPDATA%\Programs\SecretIME\extension`です。導入後に移動しないでください。
拡張IDは`djbbbndacfniipaiopkjbeipamnjaneo`です。
組織のポリシーで読み込みを禁止されている環境では、管理者へ相談してください。

WindowsのChromeへストア外の拡張を自動登録する方式には制限があります。
現在はストア未配布のため、上の操作が必要です。
[Chrome公式の配布仕様](https://developer.chrome.com/docs/extensions/how-to/distribute/install-extensions)を参照してください。

## 使用後は「復元」を押す

すべてのprivate窓を閉じても、シークレット設定は自動でOFFにはなりません。
通常入力へ戻すときは、全ブラウザのprivate窓を閉じてから拡張の「復元」を押します。
開始前からONだった設定はOFFにしません。
状態が不明なときはGoogle日本語入力のプロパティで確認してください。

表示は最後に確認した結果です。手動変更を継続監視した結果や、学習停止の実証ではありません。

## 更新する

先に全ブラウザで連動を無効にし、private窓を閉じ、必要な復元を済ませます。
新しいSetupを実行し、導入後に各ブラウザの既存SecretIMEカードで再読み込みしてください。
更新前のファイルと登録は導入先の`backups/`に保存し、復旧情報は保持します。

以前のZIP版が別の場所へ登録されている場合、Setupは上書きしません。
先に旧版の手順で登録を解除してから、新しいSetupを実行してください。
再開するときはポップアップで連動を有効にします。

## 登録を解除する

全ブラウザで連動を無効にし、private窓を閉じ、必要な復元を確認します。
導入先の`SecretIME.Setup.exe`を開き、「登録を解除する」を押してください。
現在の導入先を指す自分のユーザーの登録だけを解除します。
ファイル・復旧情報・バックアップは保持し、IME設定には触れません。
最後に各ブラウザから拡張を削除します。

## 導入できない場合

別の場所の登録、リンクされた導入先、見知らぬ既存フォルダーには上書きしません。
エラーに表示されたバックアップ先を確認してください。
一部の復旧に失敗したと表示された場合、連動を有効にせず、状況を確認してから再試行します。
問い合わせにはエラー内容と版を記載し、入力内容・個人辞書・学習履歴を添付しないでください。
